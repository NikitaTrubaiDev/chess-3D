# Chess 3D

Локальные шахматы для двух игроков на одной 3D-доске.

## Запуск

Нужны Java 21 и доступ в интернет при первом запуске Gradle:

```sh
bash gradlew :app:run
```

Для сборки и проверки: `bash gradlew test installDist`. Готовое приложение находится в `app/build/install/app/`; запускать его можно через `bin/app` (Windows: `bin/app.bat`).

## Управление

- Левая кнопка мыши — выбрать фигуру и затем клетку хода. Доступные ходы отмечены зелёными кольцами.
- Правая кнопка мыши и движение — вращение камеры; колесо — приближение.
- `R` — начать новую партию.

Реализованы проверка шаха и мата, пат, рокировка, взятие на проходе, ничья при недостатке материала и после 50 ходов без взятия или движения пешки. Пешка автоматически превращается в ферзя. Повторение позиции пока не отслеживается; компьютерного соперника и сетевой игры нет.
